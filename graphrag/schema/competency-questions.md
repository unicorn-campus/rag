# 역량질문(Competency Question)

- 상태: 확정 (2026-10-26, 사용자 확정)
- 작성: LLM(openai/gpt-oss-120b) 초안 → 사람 검토 후 확정. 확정하면 위 줄을 `상태: 확정`으로 바꿈
- 역량질문: 그래프가 **답할 수 있어야 하는 질문 목록**. 스키마 범위를 정하고, 완성 후 시금석(litmus test, 검증 기준)으로 씀
- 근거: `references/how-to-competency-question.md`(Ontology 101 Step 1)

## 1. 기본 질문 4가지

| 기본 질문 | 답 |
|---|---|
| 도메인 | 대한민국 특허법(법률 제21134호, 2025. 11. 11. 시행) 본문 제1장 ~ 제12장 조문. 부칙은 범위 밖 |
| 용도 | GraphRAG 실습용 조문 관계 질의응답. 벡터 검색만으로 어려운 '누가-무엇을-언제까지-어떤 효과' 연결과 조문 간 참조를 따라가는 다중 단계 질문에 답함 |
| 답할 질문 유형 | 정의·요건 / 주체·절차 / 기간·기한·금액 / 효력·제한·구제 |
| 사용자와 관리자 | 사용자: AI Boot Camp 교육생(사내 직원, 법률 비전문가). 관리자: 강사·데이터 엔지니어(스키마와 인덱싱 관리) |

## 2. 역량질문 목록

| ID | 질문 유형 | 역량질문 | 답이 있는 대표 조문 |
|---|---|---|---|
| CQ01 | 정의·요건 | 특허를 받을 수 있는 발명의 요건은 무엇인가? | 제29조(특허요건) |
| CQ02 | 정의·요건 | 특허를 받을 수 없는 발명은 어떤 것인가? | 제32조(특허를 받을 수 없는 발명) |
| CQ03 | 주체·절차 | 특허출원심사의 청구는 누가 할 수 있는가? | 제59조(특허출원심사의 청구) |
| CQ04 | 주체·절차 | 특허거절결정에 불복하려면 누구에게 어떤 심판을 청구하는가? | 제132조의17(특허거절결정 등에 대한 심판) |
| CQ05 | 기간·기한·금액 | 특허출원심사의 청구는 언제까지 할 수 있는가? | 제59조(특허출원심사의 청구) |
| CQ06 | 기간·기한·금액 | 특허권의 존속기간은 언제부터 언제까지인가? | 제88조(특허권의 존속기간) |
| CQ07 | 기간·기한·금액 | 특허권을 침해한 자는 어떤 형벌을 받는가? | 제225조(침해죄) |
| CQ08 | 효력·제한·구제 | 특허권의 효력이 미치지 아니하는 경우는 무엇인가? | 제96조(특허권의 효력이 미치지 아니하는 범위) |
| CQ09 | 효력·제한·구제 | 특허권을 침해당한 특허권자는 어떤 청구를 할 수 있는가? | 제126조(권리침해에 대한 금지청구권 등), 제128조(손해배상청구권 등) |

## 3. LLM 초안 대비 수정 내역

| LLM 초안 | 처리 | 이유 |
|---|---|---|
| 특허출원심사의 청구는 누가 언제까지 할 수 있는가? / 출원심사 청구를 할 수 있는 기간은 언제까지인가? | 주체(CQ03)와 기한(CQ05)으로 나눔 | 두 질문의 기한 부분이 겹치고, 질문 하나에 한 가지만 묻기 위함 |
| 특허출원인이 대리인을 선임하거나 교체하도록 명령받을 수 있는 절차는? | 빼고 CQ04(거절결정 불복)로 바꿈 | 교육생이 물을 가능성이 낮고, 조문 둘 이상을 잇는 다중 단계 질문이 필요함 |
| 특허료는 언제부터 얼마씩 납부해야 하는가? | 빼고 CQ06(존속기간)·CQ07(형벌)로 바꿈 | 금액이 별표·시행령에 위임되어 본문에 답이 없음 |
| 재심으로 회복된 특허권의 효력은 어떤 경우에 제한되는가? | 빼고 CQ08(효력이 미치지 않는 범위)로 바꿈 | 범위가 좁음. 효력 제한의 일반 질문이 우선 |
| 침해 금지청구는 어떤 경우에 할 수 있으며, 요구하는 조치는? | CQ09로 고침 | 질문 하나에 두 가지를 물음 |
